# Triage Labels

The skills speak in terms of five canonical triage roles. This file maps those roles to the actual label strings used in this repo's issue tracker.

All five **already exist** in `hexlet-volunteers/hexlet-sicp` with the canonical names, so no mapping is needed — the right-hand column is identical to the left.

| Label in mattpocock/skills | Label in our tracker | Meaning                                  |
| -------------------------- | -------------------- | ---------------------------------------- |
| `needs-triage`             | `needs-triage`       | Требует оценки мейнтейнера               |
| `needs-info`               | `needs-info`         | Ждём ответа репортёра                    |
| `ready-for-agent`          | `ready-for-agent`    | Полностью специфицирован, можно отдать автономному агенту |
| `ready-for-human`          | `ready-for-human`    | Нужна человеческая реализация            |
| `wontfix`                  | `wontfix`            | Will not be actioned                     |

When a skill mentions a role (e.g. "apply the AFK-ready triage label"), use the corresponding label string from this table.

Triage labels describe **state**, not topic. Combine them with the topical labels listed in `issue-tracker.md` (`frontend`, `security`, `compliance`, …) rather than replacing them.

Edit the right-hand column if the vocabulary in the tracker ever changes.
