# URL приходят с бэкенда, Ziggy не используется

Маршруты приложения обёрнуты в группу с `'prefix' => LaravelLocalization::setLocale()` (`routes/web.php`), а `hideDefaultLocaleInURL = true` — то есть `en` живёт без префикса, `ru` — под `/ru`. Префикс вычисляется **в момент регистрации роутов**, из контекста запроса. Поэтому `php artisan ziggy:generate`, запущенный в CLI, получил бы локаль `en` и записал бы в манифест все пути **без** префикса, а `route()` на фронте молча возвращал бы en-URL для русских пользователей.

Решено обходиться без Ziggy: все URL вычисляются на бэкенде в контексте запроса и приезжают готовыми — в пропах страницы, внутри DTO (`showUrl`, `editUrl`, `updateUrl`, `destroyUrl`) и в `links[]` пагинатора.

Это не гипотетический риск. В коде уже есть четыре бага этого класса, появившиеся именно из склейки URL в JS: `resources/js/components/ControlBox.jsx:63`, `resources/js/components/Settings/ProfileForm.jsx:18`, `resources/js/components/Settings/SettingsLayout.jsx:23` и `:31`. Под `/ru` эти ссылки уходят на en-версию и молча переключают локаль сессии.

## Considered Options

**Ziggy + обёртка, подставляющая локаль из shared-пропа** — работоспособно, но обёртка становится местом для тонких багов: `hideDefaultLocaleInURL` требует особого случая для `en`, маршруты `api.*` живут вне локализованной группы, `sitemap.xml` тоже, и отдельно надо решать `absolute: true`.

**Перенести префикс в явный параметр маршрута (`prefix('{locale}')` + `where`)** — тогда Ziggy работает без костылей, но это переписывание маршрутизации всего сайта и бой с mcamara: затрагивает все 54 маршрута, `hideDefaultLocaleInURL`, middleware `localeSessionRedirect`/`localizationRedirect`, hreflang-компонент, sitemap и 13 Playwright-тестов с захардкоженным `/ru`. Отдельный крупный риск поверх миграции фронтенда — не сейчас.

## Consequences

- Пропов больше: URL для каждой строки списка считает бэкенд
- URL нельзя построить в произвольном месте компонента — если он нужен, его надо добавить в DTO
- Побочная выгода: `localizationRedirect` отдаёт 302, а для POST/PUT/DELETE через axios это означает повтор тем же методом на новый URL и 405. Раз все URL приходят с уже правильным префиксом, рассогласования не возникает
- Если Ziggy когда-нибудь понадобится, начинать надо не с него, а с переноса префикса локали в явный параметр маршрута
