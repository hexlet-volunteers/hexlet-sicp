Хьюго Дум спрашивает, почему нельзя было написать `sqrt-stream` более простым способом, без внутренней переменной `guesses` :

```scheme
(define (sqrt-stream x)
  (cons-stream 1.0
               (stream-map (lambda (guess)
                             (sqrt-improve guess x))
                           (sqrt-stream x))))
```
